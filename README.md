# Repositori del Projecte

## Descripció
Aquest repositori correspon al projecte que consistirà en el desenvolupament d’una **web d’un chatbot**.

## Objectiu
L’objectiu principal del projecte és crear una pàgina web que permeti als usuaris interactuar amb un chatbot de manera senzilla i intuïtiva.

## Funcionalitats
- Interacció amb el chatbot a través d’una interfície web  
- Respostes automàtiques segons les preguntes de l’usuari  
- Possibilitat d’ampliar funcionalitats en el futur

## Tecnologies
El projecte utilitzarà tecnologies web i un chatbot programat en **Python**, facilitant l’escalabilitat i el manteniment del sistema.

## Estat del projecte
Actualment, el projecte es troba en fase de desenvolupament.
